# 后台与鉴权 · 设计（2026-10-22）

> 状态：已确认（四节逐节过审）· 参考实现：`~/code/wen-yuan`（wenyuan_v1）
> 范围：**登录/注册（1:1 还原 v1）+ 后台书籍管理（只读 + 导入）**
> 不在范围：模型配置 / 角色工作台 / 技能库 / Web 触发付费解析

## 一、为什么做、做到哪一步

v3 当前只有 `(graph)` 与 `(viewer)` 两个路由组，**没有任何鉴权与后台**；运营（导入新书、看解析状态与成本）只能靠命令行。v1 已有完整后台与登录页，因此本次是「把 v1 的壳搬过来、把后端换成 v3 的 Drizzle」。

三条硬边界（不改地基）：

1. **不改解析管线**：`importing` 模块原样复用，后台只负责写 `books/chapters/paragraphs`；解析仍由 `pnpm analyze` 触发。
2. **不产生付费调用**：后台任何按钮都不触发 LLM。
3. **不碰 `external_knowledge`**：它以规范名为键，导入新书不触碰。

## 二、架构

```
/login                    登录 + 注册（Client Component，Tabs 双页签）
/admin                    后台壳（Server Component，二次鉴权）
/admin/books              书籍列表
/admin/books/[id]         书籍详情（章节/实体/关系/最近 run/成本）
/admin/books/import       导入（上传 txt → 建作品）
/admin 之外               /api/auth/{login,register,logout} · /api/admin/{books,import}
```

鉴权**双层**（照 v1）：

- `src/middleware.ts`：入口门禁，匹配 `/admin/:path*`，验 Cookie 后放行或重定向 `/login?redirect=…`；
- `src/app/admin/layout.tsx`：二次校验 + 查 `is_active`（禁用账号立即失效）。第二层不是冗余，是中间件匹配遗漏的兜底。

分层（沿用 v3 约定）：

```
src/server/modules/auth/      password · token · session · rate-limit · index
src/server/modules/admin/     books-query · import-book
src/server/db/schema/users.ts 第 14 张表
src/app/api/**/route.ts       Route Handlers（Node runtime）
```

## 四、鉴权实现

| 项 | 决定 | 理由 |
|---|---|---|
| 密码哈希 | `crypto.scrypt`，串格式 `scrypt$N$r$p$salt$hash`（`N=16384,r=8,p=1`），校验用 `timingSafeEqual` | 零依赖、跨平台（门禁必须在 Windows 镜像跑）；参数自描述，未来可平滑升级。**不用 argon2**（原生模块风险） |
| 令牌 | `jose` HS256，payload `{sub, role, name}`，TTL 7 天 | 与 v1 同；边缘运行时可用 |
| Cookie | `httpOnly + sameSite=lax + secure(prod) + path=/` | 防 XSS 读取与 CSRF |
| `JWT_SECRET` | **不进 `infraEnvSchema` 全局必填**，鉴权模块自读自校验 | 否则 `pnpm analyze` 在未配密钥时会被拖失败 |
| 限流 | 内存 Map，按 IP `5 次失败 / 15 分钟`，成功清零 | 与 v1 同；进程重启归零属可接受降级 |
| 注册 | 真可用：写 `users`，邮箱/用户名唯一，密码 ≥ 8，**角色恒为 `VIEWER`** | 首个 ADMIN 由 seed 脚本创建 |
| 首个管理员 | `scripts/seed-admin.ts`，按邮箱 upsert（幂等），密码从参数/环境变量读 | 不把密码写进仓库 |

错误语义：登录失败统一文案「账号或密码错误」，不泄漏账号存在性。

## 五、页面还原（1:1）

`/login` 逐块对照 v1：左栏 logo + 大标题 + 三行统计；右栏 `ThemeToggle` + Tabs（登录/注册）+ Card + 图标输入框 + Alert + 记住我 + 分割线 + GitHub 按钮 + 页脚条款。

**四处必要偏离**（其余像素级一致）：

1. 左栏统计 → **服务端实时查库**（作品数 / 实体数 / 关系数），不照搬 v1 的 47/8640/43200；
2. 注册 Tab → **接真实接口**（v1 是 UI 占位）；
3. GitHub 按钮 → 保留外观 + `disabled`（v1 同样未实现）；
4. 忘记密码 → 保留视觉、**不复制 v1 的 `/forgot-password` 死链**，改为点击提示「请联系管理员重置」。

自定义样式类从 v1 `globals.css` 逐条移植：`login-page / login-layout / login-left / login-right / login-auth-shell / login-divider-pill / interactive-text-link`，令牌用 v3 同名 `--color-*`，不引入新颜色，四主题自动适配。

`/admin` 用 **header 式布局**（与 v1 一致）。判断依据：一级模块 ≤3 用 header，≥4 换侧边栏；本期 2 个（仪表盘/书籍），且书籍表有 7 列，宽度比导航重要。
