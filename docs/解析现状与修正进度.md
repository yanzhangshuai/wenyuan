## 1. 当前解析现状

### 1.1 系统在做什么

文渊 v3 是一个**「LLM 当算子」的固定流水线**，不是 agent：

- **只有 2 个 LLM 调用点**：`dictionary`（P0，每本书 1 次）、`extract`（P1，每个分片 1 次）。
- 其余阶段 **P2–P6 全是确定性纯代码**（归并 / 投票 / 聚合 / 落库）。
- 因此**成本线性可预测**：全书 token 消耗 ≈ 分片数 × 单片成本 + 1 次词典。

```
P0 词典 ──► P1 提取 ──► P2 grounding ──► P3(已删) ──► P4 投票 ──► P5 归并 ──► P6 聚合落库
 (LLM×1)     (LLM×N)      纯代码            —          纯代码        纯代码        纯代码
```

关键设计约束：**准确率不靠 prompt 技巧，靠确定性工序**（参考 AI-Reader-V2 的方法论）。
改 prompt（P0/P1）**不可 $0 预演**；改 P2–P6 **可在库内精确重放**（$0）。

## 2. 准确率：三份金标（2026-10-14 当场重跑）

金标是**人工穷尽标注**的「尺子」，位于 `scripts/eval/gold/`。
**实体指标只比成员名集合、不比 `type`** → 类型质量需另用 `_wb_graph_audit.mjs` 一类的审计。

| `rulin-waishi-1-3`（78 实体 / 22 关系） | 第 1–3 回 | 98.46 / 82.05 / **89.51** | 71.43 / 68.18 / **69.77** |
| `hongloumeng-1-3`（134 实体 / 58 关系） | 第 1–3 回 | 93.22 / 82.09 / **87.30** | 83.33 / 51.72 / **63.83** |

### 2.1 怎么读这张表

- **实体精确率很高**（93–100%），**召回是主要短板**（79–82%）。
  → **儒林 1-1 的实体 FP 已经归零** → 该区间**只能动召回侧**，不能再动提及口径（V1 试过，−2.85/−4.72，已回退）。
- **关系侧显著低于实体侧**（F1 63.8–75.0），**召回尤其低（红楼 51.7%）**。
  → **头寸在关系侧**。

### 2.2 关系错误的头号成因：**同一人被拆**

实测归因（红楼 1-3）：

- **75% 的关系 FP 来自「同一人被拆成多个实体」**。
- 机制：`metrics.ts` 的 `buildEndpointResolver` 把关系端点解析到**系统自己**的实体下标
  → 「金标写 `贾赦`、系统写 `赦老爷`」会让该条关系**两边都配不上** → **同一条边同时计 1 FP + 1 FN**。
- **推算**：一个切分点 ≈ **1 条实体 FP + 该人每条关系的 FP/FN 各一条**。

→ 所以**「归并」是关系侧唯一的大旋钮**（见 §3.4 `aliasGroups`）。

### 2.3 第二成因：**关系闭集缺码**

当前关系目录是**闭集 10 码**（`src/lib/relations.ts`）：
`父子 / 母子 / 兄弟 / 夫妻 / 师生 / 同年 / 同僚 / 主仆 / 朋友 / 仇敌`。

缺失的关系类别（实测在原文里明确存在、但无码可落）：

| 缺失类别 | 实例 | 系统当前行为 | 后果 |
|---|---|---|---|
| **祖孙 / 外祖孙** | `贾母 → 宝玉/迎春/探春/惜春` | 用 `母子` 顶替 | 语义错 → 1 FP |
| **姻亲（岳婿 / 郎舅 / 亲家）** | `胡屠户 ↔ 范进`、`周进 ↔ 金有余`、`申祥甫 ↔ 夏总甲` | 分别报成 `父子` / `朋友` / `朋友` | 3 FP |
| **义父子 / 君臣** | `翟买办 → 秦大汉`、`太祖 → 危素` | 就近取 `父子` / `主仆` | 前者 1 FP + 1 FN |

> ⚠️ **这是「目录缺口」，不是抽取错误** —— 读 PRF 报告时不要当成系统 bug。
> 「补码」的**真实射程只有 6/10**（详见 §4.1），且**代价是付费 + 必须同时重标自有金标**。

### 2.4 尺子本身的已知限制（读数字前必须知道）

1. **实体总数是坏指标** —— 归并/切分都会改变它，且分不清「改好」还是「改坏」。
2. **同代码 + 同输入也会跳** —— `temperature: 0` **不可复现**：
   实测**实体极差 ~7 点、关系极差 ~37 点**（一次性大样本）。→ **单跑 ΔF1 不可直接归因**。
   判据必须写成「**方向 + 机制**」，而不是 F1 差值。
3. **切片尺子有盲区** —— 只看区间内的名字集合，**看不见「过度归一化」**
   （如 `文昌帝君` 命中 `文昌` 也计 TP）。
4. **`intimate` 类不可达** —— ChiNovelKE 官方 5 类里 `intimate` 在 v3 无对应码 → **加什么码都赢不了**，已登记为「不可比」。
