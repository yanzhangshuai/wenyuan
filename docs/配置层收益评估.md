# 配置层收益评估（2026-10-26）

> **结论先行**：自动生成的作品包（专名词典 + 别名组）对新书的质量提升 **≈ 0**（F1 +0.25 → −0.28，均在噪声内）。
> 瓶颈不在配置层，在 P1 抽取。**不再往词典/别名组投入**，除非先动 P1。

## 为什么做这个评估

后台上了「导入 → 自动生成配置 → 审核 → 解析」的完整链路，但一直没人验证过：
**自动生成的配置，到底比不配强多少？**

不验证的后果是：所有关于「加一本书要多久」的承诺都建立在假设上。

## 实验设计

三组对照，**唯一变量是「有没有配置」**：

| 组 | 文本 | 分片 | 模型 | 配置 |
|---|---|---|---|---|
| 对照 | 红楼 1–10 回 | 24 片 | deepseek-flash | 空词典 |
| 实验 A | 同上 | 同上 | 同上 | 自动生成 60 专名 / 26 组 |
| 实验 B | 同上 | 同上 | 同上 | 自动生成 72 专名 / 28 组（扩充称谓后缀后） |

金标：`scripts/eval/gold/hongloumeng-1-3.json`（134 实体 / 58 关系，覆盖第 1–3 回）。

## 结果

| 组 | P | R | F1 |
|---|---|---|---|
| 空词典 | 85.56% | 57.46% | **68.75%** |
| 实验 A | 83.16% | 58.96% | **69.00%** |
| 实验 B | 86.36% | 56.72% | **68.47%** |

三轮全在 68.5–69.0 之间。**配置的净贡献是 0**（单次运行波动约 ±3 点，这三个数的差异全在噪声内）。

## 为什么是 0

### 词典扩大了候选面，别名组没同步覆盖

实验 A 比对照组多出的 FP，全是**同人异名碎片**：

```
政老前辈、士隐、贾赦、太君、如海
```

机制：有词典时，这些写法被切成**整词** → 进入候选 → P1 抽成独立实体 → 而自动生成的别名组没覆盖它们 → 碎片留下。
无词典时这些词压根没被切成整词，反而不产生碎片。

实验 B 扩了称谓后缀，这 5 个碎片确实并回了本体（FP 16 → 12），
但 TP 也从 79 掉到 76，F1 正好抵消。

### 真正的 FN 大头与配置无关

两组实验的 FN 构成完全一致：

| 类别 | 数量 | 例子 | 归属 |
|---|---|---|---|
| 列举式引文 | 40 | 尧/舜/禹/曹操/陶潜/卓文君 | **分片策略**：第 2 回那段 50 人名单被 24 片拆散，模型看到半截 |
| 具名处所 | 6 | 东鲁/三生石/离恨天/灌愁水 | **P1 不抽这类** |
| 具名概念 | 2 | 秘情果/人参养荣丸 | 同上 |
| 具名人物 | 4 | 女娲氏/宁国公/贾复/李纨 | 分散 |

**空词典也有 68.75%** —— 这是最关键的证据：P1 不依赖专名词典就能抽到主要人物。

## 那内置包为什么有用

不是因为它让 P1 抽得更多，而是因为**它的 32 组别名组把碎片并回了本体**：

- 内置包（32 组）：红楼 1–3 回切分 FP **8 → 0**
- 自动生成（26 组）：切分碎片重新出现

人工策展的价值在**别名组的召回**，不在词典规模。

## 决策

**不再往配置层投入。** 理由：

1. 边际收益已量化 ≈ 0；
2. 要动就得动 P1（分片策略 / 提示词），那是**不可 $0 预演**的改动 ——
   会改变 P1 输出，需要重跑全书验证，且可能引入新噪声；
3. 而 P1 的收益空间主要是「多抽 40 个典故人物」—— 对「小说人物关系图谱」这个产品价值有限。

## 当前定位

| 场景 | 用什么 | 质量 |
|---|---|---|
| 儒林 / 红楼 | 内置包（人工策展） | 高（红楼实体 F1 89.41） |
| 新书 | 自动生成（兜底） | 与空词典相当，主要人物能抽到 |
| 想提升新书质量 | 人工在页面上补别名组 | 取决于投入 |

**「加一本书 10 分钟」买到的是「能跑通」，不是「质量」。**

## 什么情况下应该重新评估

- P1 的分片策略变了（比如按段落边界切，而不是按字数）
- P1 的提示词要求抽取具名处所/概念
- 换了更强的模型

以上任一发生，用同一套三组对照复测即可 —— 复现方式见下。

## 复现方式

```bash
# 1. 导入红楼 1-10 回，书名避开「红楼梦」（否则会命中内置包，自动生成被禁）
# 2. 不生成配置直接解析 → 对照组
# 3. 生成配置后重新解析 → 实验组
# 4. 两组各跑一次：
pnpm eval scripts/eval/gold/hongloumeng-1-3.json --work-id <bookId>
```

⚠️ **不要拿「10 回样本的 69%」和「120 章全书的 89.41%」直接比** ——
那 20 点里大部分来自规模（分片粒度不同），不是配置差距。
